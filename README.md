# Loan_status_prediction 🪙
<br>
• This application predicts whether a loan application will be approved or rejected
based on applicant details such as age, income, employment length, loan intent, and credit history. 
<br/>
• It uses a trained Random Forest model along with a preprocessing pipeline to deliver real-time predictions.
Simply fill in the details and click Predict Loan Status to get the result.
